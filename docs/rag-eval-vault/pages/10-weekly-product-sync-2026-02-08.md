# 기계 학습 메모

- 기계 학습은 규칙을 직접 다 적지 않고 데이터에서 패턴을 학습하는 접근이다.
- retrieval quality 개선에서도 statistical pattern과 representation learning이 중요하다.
- 관련 문서: [[자연어 처리 메모]], [[모델 평가 로그]], [[ONNX Runtime 메모]].

## 실무 감각

- benchmark score가 좋아도 우리 note corpus에 안 맞을 수 있다
- heading-heavy short bullet note는 일반 문장 데이터와 다르다
- local inference 성능도 실제 제품성에 큰 영향을 준다
