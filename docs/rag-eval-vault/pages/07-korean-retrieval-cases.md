# 검색 엔진 메모

- 검색 엔진은 수집, 색인, ranking이라는 흐름을 가진다.
- 사용자 체감에서는 crawler보다 snippet과 rank ordering이 더 중요하게 느껴진다.
- 관련 문서: [[정보 검색 메모]], [[검색 품질 회고]], [[SQLite 학습 노트]].

## 간단 메모

- 문서를 모은다
- 색인을 만든다
- 질의와 관련 있는 결과를 순서대로 보여준다

## Sandpaper 쪽 해석

- note app에서도 작은 검색 엔진처럼 생각할 수 있다
- title match, snippet quality, landing quality가 실제 UX를 좌우한다
