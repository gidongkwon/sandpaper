# 고객 인터뷰 민지

- 민지는 note title보다 meeting fragment로 검색하는 편이다.
- 한국어 문장에 English technical noun이 자주 섞인다.
- 관련 문서: [[개인 검색 마찰 메모]], [[고객 인터뷰 Daniel]], [[검색 품질 회고]].

## 직접 표현

- `command palette`라는 이름은 괜찮지만 실제로는 note launcher처럼 쓴다
- exact page title은 잘 기억이 안 난다
- snippet이 너무 짧으면 맞는 결과인지 모르겠다

## 실제 검색 예시

- 재색인
- provider mismatch
- 지난주 sync에서 command palette 얘기한 것
