# 자연어 처리 메모

- 자연어 처리는 자연어를 컴퓨터가 다룰 수 있게 만드는 분야다.
- 정보 검색, 문서 분류, 질의응답, 번역 같은 응용과 가깝다.
- 관련 문서: [[기계 학습 메모]], [[한국어 처리 메모]], [[정보 검색 메모]].

## 이 note에서 중요한 것

- NLP는 정보 검색과 맞닿아 있다
- 문서 분류와 query understanding이 retrieval 품질에 영향을 준다
- rule-based에서 statistical, neural 접근으로 이동해 왔다

## 검색 평가 관점

- query wording이 조금 달라도 비슷한 문서를 찾을 수 있어야 한다
- bilingual note retrieval은 NLP 문제와 맞닿아 있다
