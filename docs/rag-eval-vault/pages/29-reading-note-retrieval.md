# Retrieval reading note

- retrieval은 단순 match보다 ranking problem으로 보는 편이 실무에 가깝다.
- exact hit, partial overlap, semantic neighbor의 균형이 중요하다.
- 관련 문서: [[정보 검색 메모]], [[벡터 공간 모형 노트]], [[검색 엔진 메모]].

## 실무 해석

- exact title hit는 강하게
- weak semantic hit는 snippet quality로 보완
- paraphrase recall이 한국어에서 특히 중요
