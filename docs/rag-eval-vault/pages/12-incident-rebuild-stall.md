# 한국어 처리 메모

- 한국어는 형태 변화와 어절 경계 때문에 naive tokenization만으로는 retrieval이 약해질 수 있다.
- 같은 뜻을 여러 표현으로 쓰는 경우가 많아서 paraphrase 대응이 중요하다.
- 관련 문서: [[자연어 처리 메모]], [[한영 검색 용어집]], [[Korean Retrieval 테스트 메모]].

## 예시 표현

- 재색인
- 인덱스를 다시 만든다
- 색인을 새로 생성한다

## 왜 중요한가

- exact string match만으로는 실제 검색 습관을 못 따라간다
- heading 아래 짧은 bullets는 더 어렵다
