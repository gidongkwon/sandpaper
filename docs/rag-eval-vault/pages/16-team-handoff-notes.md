# 위키백과 메모

- Wikipedia는 collaborative encyclopedia라서 topic coverage가 넓다.
- 평가 corpus source로는 좋지만, 원문 그대로보다 note-style 재구성이 더 실용적이다.
- 관련 문서: [[평가용 vault 인덱스]], [[검색 개선 로드맵]], [[개인 검색 마찰 메모]].

## 왜 그대로 복붙하지 않았는가

- encyclopedic prose만 있으면 note retrieval과 다르다
- real-world note처럼 짧은 bullet과 mixed-language phrasing이 필요하다
- 검색 품질 차이는 보통 messy note에서 더 잘 드러난다
